4. 💻 CUSTOM TERMINAL & CODE EXECUTION
--------------------------------------------------------------------------------
• "Open terminal" / "Show terminal" / "Terminal open"
  -> Opens the integrated custom PowerShell/CMD terminal in the JARVIS UI.
• "Run command <cmd>" / "execute <cmd>" / "<cmd>"
  -> Runs any shell command with full laptop and drive access.
  Examples:
    - "run python --version"
    - "run ipconfig"
    - "run dir D:\personal-ai-full"
    - "pip install requests"
    - "Get-Process | Select-Object -First 5"
• Compound Code Creation & Execution:
  - "create a file name demo.py and write binary search in python and run the code"
  - "create a file test.py and write bubble sort and run it"
  -> Automatically writes clean, runnable code, saves it to disk, executes it
     inside the custom terminal, and reports the verified output.
